# Contributing to Rhen

Rhen is early research software. Before proposing code, read the M0 language reference and architecture notes.

Every behavioral change requires a reproducible example, documented semantics, and positive and negative tests. Run `npm run check` and `npm test` on Node.js 22+. Declare whether grammar, IR version, backend semantics, runtime behavior, or output safety boundaries change.

Do not submit confidential client code, personal data, credentials, or unpublished creative work. AI-assisted contributions must meet the same verification and human-review standard as any other contribution. A merged PR is not peer-reviewed scientific evidence.
